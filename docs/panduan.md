# Panduan Penggunaan EXAMLAB V31

## Menjalankan website
- Ekstrak arsip ZIP.
- Jalankan `index.html` menggunakan Chrome atau Edge.
- Halaman akses login akan tampil sebelum beranda.
- Login sesuai peran akun siswa atau Owner.

## Jika tombol tidak merespons
1. Tutup tab website lalu buka ulang `index.html`.
2. Pastikan menggunakan versi file yang berasal dari ZIP ini.
3. Coba Chrome atau Edge versi terbaru.
4. Tekan `Ctrl + Shift + R` untuk memuat ulang penuh jika file dibuka melalui server lokal.
5. Periksa Console browser (`F12` → Console) untuk pesan error.

## Penyimpanan
Data yang menggunakan localStorage/sessionStorage mengikuti profil browser dan perangkat yang digunakan. Menghapus data browser dapat menghapus sesi atau data lokal.

## Pengembangan
Buka folder proyek melalui Visual Studio Code. Karena aplikasi saat ini berbentuk standalone, file utama yang diedit adalah `index.html`.
